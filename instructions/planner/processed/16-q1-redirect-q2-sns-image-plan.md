## 임무
1. **Q1 리다이렉트 사양**
   - 새 id를 정한다. 비공인 실명 로마자를 빼고 형식 규칙을 지킨다.
   - 옛 id → 새 id 리다이렉트 방식을 고른다. 후보: `next.config` redirects, 폐기 id 목록 파일 등. 정적 배포(SSG)에서 되는 방식이어야 한다.
   - 다음 처리 기준을 정한다: 308/301 중 무엇을 쓸지, 영어 주소, 사이트맵 제외, canonical, 내부 링크 갱신, 이미지 폴더 이름.
   - 같은 일이 또 생길 때 쓸 수 있도록 일반 규칙으로 쓴다. 예: `retiredIds` 목록과 검증.
2. **Q2 소개 문구(C4 재정정)**: "SNS 원문 이미지는 정리 중"이라는 현황을 사실대로 반영한 ko/en 문안을 만든다. 과장과 거짓이 없어야 한다.
3. **SNS 140건 정리 계획**
   - 실제 수를 다시 센다. self 이미지 가운데 원문 SNS 이미지를 저장한 것과 자체 제작 등 나머지를 나눈다.
   - 정리 방법별 장단점을 정리한다.
     - ① 원문 SNS 이미지 핫링크: 인스타그램·스레드가 외부 핫링크를 허용하는지, 주소가 만료되는지(서명 URL 여부)
     - ② 근거 언론 기사 이미지(B)로 교체
     - ③ 대체 카드
   - ①은 실제로 되는지 표본 5건 이하로 시험한다. curl에 외부 Referer를 넣어 응답 코드, 만료 파라미터, 시간이 지난 뒤 재요청 결과를 본다. 결과는 사실만 적는다.
   - 권장 순서와 묶음 단위를 정한다. 기존 지침(10건 묶음·리뷰어 게이트)과 맞춘다.
4. **코드 반영 목록 갱신**: 프로그래머 16의 최종 범위를 표로 만든다(C3·C4 재정정·C5·Q1 리다이렉트).
