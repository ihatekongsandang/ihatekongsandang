## 임무 — v0.1 프로토타입 (열람 전용, 4화면, 배포 가능 상태)

### 1. 프로젝트 초기화
- Next.js 15(App Router) + React 19 + TypeScript + Tailwind + shadcn/ui, `package.json` name `ihatekongsandang`. Node ≥20.
- `TECH_STACK.md` 작성 — 선택·버전·근거. 특히: 마크다운 파서·sanitize 라이브러리, 이미지 처리(`next/image` `remotePatterns` — 핫링크 정합), CSP 전략(§7-7 택일 근거), JSON-LD 타입 제안(`NewsArticle` 대신), `llms.txt` 도입 여부.
- `vercel.json` 보안 헤더(HSTS·nosniff·frame DENY·Referrer-Policy·Permissions-Policy·CSP Report-Only부터).
- `.env.example`(`NEXT_PUBLIC_SITE_URL`, `NEXT_PUBLIC_GA_ID` — v0.1.5에서 주입, 값 비움). `.gitignore`에 `.env*.local`.

### 2. 콘텐츠 스키마 + 검증 (`content/README.md` + `scripts/`)
- frontmatter 스키마를 §7-2 그대로: 필수 `id`(frontmatter 명시·URL-safe·중복 오류) · `title` · `description` · `publishedAt` · `status`(5종 enum: `의혹|수사중|기소|유죄판결|종결`, `유죄판결`은 `courtLevel` 1심/2심/확정 필수) · `sourceType`(`url|photo|photo_text`) · 출처 표기 · `sources[]` 최소 1건(type 언론/수사기관/법원/기타 · name · url · date) · 이미지당 `alt`. 선택 `tags[]` · `statusHistory[]` · `submittedBy` · `image`(대표) · `useSourceImage`(기본 false). **카테고리 없음.**
- URL 유형 추가 필드: `sourceUrl`, `og.title/description/image/siteName`, `titleOverride`/`descriptionOverride`.
- `scripts/validate-content.mjs` — 빌드 전(`prebuild`) 필수 필드·enum·id 중복·alt·sources≥1 검사, 실패 시 빌드 중단. 🔴 이것이 CLAUDE.md §5 "콘텐츠 게시 예외"의 게이트다.
- `scripts/og-draft.mjs <url>` — OG 메타 추출해 frontmatter 초안 출력(슈퍼바이저 게시 편의). 추출 실패 시 빈 필드로.
- `content/README.md` — 슈퍼바이저가 이 문서만 보고 게시 파일을 쓸 수 있는 수준: 3종 유형별 완성 예시, 필드 표, 라벨 정의(PRD §6①), 검증 실행법, 이미지 넣는 법(`public/images/{id}/`).
- 샘플 게시물 3건(URL·사진·사진+글 각 1) — ⚠️ **실제 인물·실제 사건을 쓰지 않는다.** 가상의 예시(예: "예시 사건 A")로, 이미지는 자체 제작 플레이스홀더. 실제 언론 URL도 넣지 않는다(리뷰·테스트용이므로).

### 3. 4화면 (반응형 — 모바일 1열 → 태블릿 2열 → 데스크톱 3~4열)
- `/` 홈 카드 피드: 카드 = 제목 + 대표 이미지(없거나 `useSourceImage:false`·핫링크 실패 시 플레이스홀더) + 상태 배지. 본문·요약 미노출. 최신순. 초기 N장 SSG + "더 보기"는 `<a href="?page=n">` 실제 링크(JS 무한스크롤은 점진적 향상). N 기본값·근거 기록.
- `/tag/[slug]` 태그 피드(같은 카드·페이지네이션).
- `/post/[id]` 상세: 상태 배지 + 근거 출처 링크 목록 + 상태 이력(있으면) + 유형별 본문(URL: OG 요약·원문 링크 외부 이동 CTA·출처 / 사진·사진+글: 원본 화질·갤러리·본문 마크다운 sanitize) + 태그.
- `/about` 소개: 익명 운영 · 출처·저작권 정책 요약 · 상태 라벨 정의 · 정정·삭제 요청 연락 채널(플레이스홀더 이메일 — 사용자 확정 전) · AI 작성 "고지" 문구는 넣지 않는다.
- 외부 링크: `target="_blank" rel="noopener"` + 외부 이동 아이콘. 마크다운 렌더러 자동 rel과 충돌 확인.
- 자체 `og:image`(로고/플레이스홀더, 원문 썸네일 재사용 금지) · 게시물별 title/description · `sitemap.xml`·`robots.txt` 자동 생성 · 태그 페이지 canonical · JSON-LD.
- GA4 이벤트 계측 지점 2종(카드 노출·카드 클릭) 준비 — 측정 ID 없으면 no-op.
- 접근성: 키보드 탐색·포커스 인디케이터·색 대비 4.5:1·`alt`.
- 디자인: 기본 Tailwind+shadcn, "담백한" 톤. 커스텀 디자인은 v0.2 디자이너 몫 — 과투자 금지.
