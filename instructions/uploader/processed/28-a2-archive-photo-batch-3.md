# 업로더 28 — 인물 없는 자료사진(A-2) 묶음 3 (지금 허용 범위 안에서 최대한)

- 출처 한정은 업로더 27과 같다. CC BY 2.0/3.0/4.0(버전 명시), CC0 1.0, 이용조건이 CC BY 4.0인 기증만 쓴다.

## 할 일
1. **대상**: 이미지가 없는 게시물 **전체**를 훑는다(11월 게시분 → 10월 → 9월 순서). 목표 건수는 두지 않는다. 조건을 지키는 한 최대한 채운다.
2. **국회 사진**: 항공 연작 말고 다른 원본(정면, 본회의장 외관, 의원회관 등)을 먼저 찾는다. 같은 원본은 3건까지만 쓴다(26·27 사용분 포함).
3. **검색처**: 업로더 27과 같다(서울연구데이터서비스, 위키미디어 공용, 공유마당). 위키미디어에서는 `CC-BY-2.0`, `CC-BY-3.0`, `CC-BY-4.0`, `CC0` 분류로 검색 범위를 넓힌다. Flickr에서 옮겨 온 파일은 라이선스 검증 표시가 있어야 한다.
4. 사진 확인, 저장, EXIF, frontmatter, caption은 26·27과 같다.
5. **참고 후보 목록**(다음 묶음용): 퍼블릭 도메인·CC BY-SA·공공누리 제1유형 후보를 **게시물별로 파일 URL과 라이선스 틀 이름까지** 적는다. 기획 20 확정 후 곧바로 쓸 수 있게 하기 위해서다.
   - 저장소에는 넣지 않는다.
   - 별도 파일 `docs/qa/uploader-28-candidates.md`에 쓴다. 저작자 이름은 적지 않는다.
6. **검증**: `npm run validate:content`에서 R=0이어야 하고, 해당 id에 새 경고가 0이어야 한다. `git status --short` 전체를 적는다.

## 🔴 금지
- 업로더 27과 같다. git 쓰기·빌드·`src/` 수정 금지, 인물이 나오는 사진 금지.
- 트리거·오더·히스토리·후보 파일에 사진 저작자 이름, 실명, 옛 id, 다른 서비스명, 계정, 홈 경로를 쓰지 않는다.
- `2026-10-09-gotdemcatch-…` 병합 작업 파일과 `2026-11-10-attendkdz-…` 파일은 건드리지 않는다.
