## 할 일
1. **시범 5건 고르기**
   - 대상은 `post-recheck.tsv`에서 `reviewer_2an` = `B`인 25건 중 다음 조건에 맞는 5건이다.
     - 얼굴이 없는 사진이거나, §3.1 공인이 단독으로 나오는 공적 활동 사진
     - 의혹 사안이 아닌 것
   - 고른 이유를 트리거에 적는다.
   - 5건이 안 되면 `B(교체)` 건으로 채운다.
2. **5건 판정**
   - 단계 1~4대로 원 매체 기사의 og:image를 다시 받는다.
   - 사진 설명, 사건 당시(4a), 제외 11항, 인물 3분류와 원경 측정(단계 2-1)을 확인한다.
   - 통과하면 ②로 바꾼다. 바꿀 항목은 `image`(kind news·src 핫링크·credit·sourcePageUrl·retrievedAt·faceNote·caption·alt)와 en `imageAlt`·`imageCaption`이다.
   - 불가하면 다른 근거 기사를 시도하고, 그래도 없으면 ③(대체 카드)으로 둔다. 둘 다 사유와 시도한 기사를 적는다.
3. **옛 자체 카드 파일**: ②·③ 어느 쪽이든 쓰지 않게 된 `public/images/<id>/` 파일은 선례대로 처리한다(참조 없는 파일 0).
4. **본문**: 본문에 "자체 제작 카드" 취지 문장이 있으면 선례대로 고친다. `updatedAt`은 지침 규칙을 따른다.
5. **검증**
   - `npm run validate:content` 통과
   - 핫링크 200
   - 참조 없는 이미지 0
   - `git status --short` 전체를 트리거에 적는다.
6. **소요 시간**: 5건에 걸린 대략의 작업 시간을 트리거에 적는다. 다음 묶음 크기를 정하는 데 쓴다.
