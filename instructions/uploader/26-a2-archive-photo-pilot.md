## 할 일
1. **대상 고르기(10건)**
   - 이미지 없는 게시물 가운데 장소·기관이 주제인 게시물을 고른다. 예:
     - DMZ·철책·전망대 게시물
     - 국회 법안·본회의 게시물 → 국회의사당
     - 통일부 → 정부청사
     - 대법원·헌법재판소 판결 게시물
   - 고르지 않는 게시물:
     - 의혹 대상이 그 기관·조직 자체인 게시물(정책 §4.5)
     - 제목이 특정 기관을 비난하는 단정형이라 건물 사진이 결합 위험인 게시물
   - 고른 이유를 트리거에 적는다.
2. **사진 찾기**
   - 검색처: 공유마당(이용조건 필터), 위키미디어 공용(CC BY·CC0·PD), 기관 누리집의 공공누리 제1유형.
   - 원 페이지에서 확인할 것:
     - 라이선스와 버전
     - 저작자(개인/기관 구분만 트리거에 적고, 이름은 frontmatter에만 쓴다)
     - 창작년도, 해상도(짧은 변 400px 이상)
   - 사진을 직접 열어 확인할 것:
     - 사람이 없는지(점 크기 인물은 얼굴 높이 1% 미만만)
     - 공사 중이거나 옛 모습이 아닌지
     - 워터마크·덧씌운 글자가 없는지
   - 같은 원본은 3건까지만 쓴다.
3. **저장**
   - `public/images/{id}/`에 저장한다.
   - 리사이즈·포맷 변환만 한다. 자르기·색 보정·덧씌우기는 하지 않는다.
   - 기증저작물은 정책 §4.5-11 규칙을 따른다.
4. **frontmatter**
   - ko `image`: `kind: open`, `src`, `alt`, `caption`, `creditName`, `creditNameEn`, `sourcePageUrl`, `sourceSiteName`, `license`, `licenseUrl`, `workTitle`, `workYear`(있으면), `retrievedAt`, `faceNote`(`얼굴 없음(자료사진·{대상})`). 필요하면 `licenseLabel`·`donorName`·`creditNotice`도 넣는다.
   - caption 형식은 `자료사진: {대상}({연도 또는 '촬영 연도 미상'}) — 이 사건 당시 사진이 아닙니다.`이고, 10년 이상 전이거나 연도 미상이면 `현재 모습과 다를 수 있습니다.`를 덧붙인다.
   - en: `imageAlt`, `imageCaption`(`Archive photo: …`).
5. **검증**
   - `npm run validate:content`는 R=0이고, 해당 id의 경고가 0이어야 한다.
   - 저장 파일의 해상도와 용량을 적는다.
   - `git status --short` 전체를 트리거에 적는다.
6. **소요 시간**을 적는다. 사진을 못 찾은 게시물과 그 사유(검색처별)도 적는다. 남은 게시물에 적용할 수 있을지 추정하는 데 쓴다.

## 🔴 금지
- git add·commit·push 금지. 빌드 금지. `src/`·설정 수정 금지.
- 인물이 나오는 사진을 A-2로 쓰지 않는다.
- CC BY-SA·NC·ND, 버전 불명, CC 지역판, 저작자 미상, 재업로드본은 쓰지 않는다.
- 트리거·오더·히스토리에 다음을 쓰지 않는다: 사진 저작자 이름, 비공인 실명, 옛 id, 다른 서비스명, 계정명, 홈 절대경로.
