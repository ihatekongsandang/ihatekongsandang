## 배경
디자인 팀장 03이 반응형 개편 진단과 브리프를 냈다. 디자이너 A·B·C가 같은 시간에 각자 시안 3개씩 만든다(모두 9개). 이후 팀장이 채점해 고른다.

사용자 결정(2026-11-09):
- U1 = a: 떠 있는 배너는 모바일·태블릿에서 자리·크기를 바꿔도 된다. "닫기 없음"은 유지한다.
- U3 = a: 홈 소개 문단(D1 확정문)은 모바일에서 한 줄 + "더보기"로 접는다. 문구는 그대로 둔다.
- U2 = a: 다크 모드는 이번에 넣지 않는다.
- U4 = a: 카드의 "링크" 유형 표기를 없앤다.
- U5 = a: 시스템 폰트를 유지하고 웹폰트는 쓰지 않는다.
- 🔴 이미지: 자체 제작 텍스트 카드(67건)를 실제 사진으로 바꾼다. 1순위는 공공누리 공공 이미지, 2순위는 언론 기사 대표 이미지다. 그래서 시안에는 다음이 있어야 한다.
  - 사진 카드의 출처 표시 자리(예: "사진: 대통령실" / "사진: {언론사}")
  - 사진이 없거나 깨질 때 쓸 새 대체 카드 디자인(지금의 회색 + 빨간 줄 카드를 대신할 것)
