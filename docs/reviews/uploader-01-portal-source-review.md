## 1. 59건 전수 대조 (임무 1)

### 1.1 방법
1. `extract_pairs.py`로 `git diff -U0 -- content/posts/`에서 포털 → 새 주소 쌍을 뽑았다. **59쌍, 46개 파일**이다. HEAD 스냅숏을 다시 세어 보니 포털 주소는 46개 파일, 59줄(http:// 2)이었다. 단계 0 규모, 리뷰 32 집계와 같다. HEAD의 포털 파일 목록과 diff 파일 목록도 46개가 같다.
2. `fetch_all.sh`로 **새 주소 59건과 옛 포털 주소 59건, 모두 118건**을 받았다(`curl -L -A "Mozilla/5.0"`, 간격 1.5초).
3. 비교 방법:
   - 같은 기사인지는 옛 포털 페이지와 새 원 매체 페이지를 비교해 판단했다. 제목은 따옴표 모양, 사이트 접미어, 호환 한자(U+F9E1 李)를 정규화한 뒤 맞췄다. 매체는 네이트 JSON-LD `author`나 h1 아래 매체 표기, 다음 `og:site_name`으로 봤다. 게재 시각도 함께 봤다.
   - `date`는 원 매체의 `article:published_time`을 KST로 바꿔 대조했다. 메타가 없거나 UTC로 나오는 7건은 페이지 안의 값을 직접 읽었다.
4. 자동 비교가 False로 나온 행은 모두 직접 열어 확인했다. 결과는 `result-59.tsv` `manual_note` 열에 있다.
