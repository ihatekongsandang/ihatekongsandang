- 썸네일 텍스트: "증언에 '이재명' 나왔다 / 서영교 역대급 자폭! / 쌍방울 대북송금 사건 증인을 불러"
- 보도로 확인된 실제 맥락 (2025-09-05 국회 법사위 법안심사1소위 검찰개혁 입법 청문회):
  - 서영교 의원이 "배상윤이 들어오면서 누구의 이름을 얘기하는 거였나요, 공항에서?"라고 묻자 조경식 전 KH그룹 부회장이 "이재명"이라고 답함
    → 증언 취지는 "배상윤 회장이 귀국하면 이재명·이화영을 연루시키라는 지시를 받았다"는 주장 (민들레 2025-09-06, 오마이뉴스)
  - 즉 "이재명이 주범"이라는 증언이 아님. 릴스의 "주범"·"자폭" 틀은 보도된 문답 맥락과 어긋남
- 추가 사정: 증언 속 권성동 의원 48억 수수 주장은 당사자 간 명예훼손·무고 고소로 다툼 중. 증인 신원·경력에 대한 반박 보도(KH 측 "직함 사칭", 전과 보도)도 있음
- 판정: 원문 핵심 주장이 보도된 사실과 반대 방향 → 게시 불가 (25사단 확산 주장 건과 같은 기준)
