# 링크 고르는 기준 — 사용자용 (2026-11-05, 리뷰 18·19 반영)

**작성**: 반공-슈퍼바이저 (Opus 5.5) | **근거**: 검토일 10/15~11/04 기준 SNS 글: 게시 불가 22·보류 9(held-recheck) + 인스타그램 수집 실패 18(캡처 대기) · 병합 6 · 신규 게시 7(커밋일 기준). 실측 `docs/tools/reviewer-18/count-output.txt`(블록 수 21·8) + 리뷰 18 P2-4(정정 블록·철원 3건 반영한 SNS 글 기준 22·9), 기준 문서 `docs/poster/guide.md` §1·§1-1·§2

업로더에게 보내기 전에 아래 표로 한 번 걸러 주시면 게시까지 가는 비율이 올라갑니다.

## 🔴 먼저 — 인스타그램은 캡처를 함께
인스타그램 링크는 현재 서버에서 내용을 읽지 못합니다(2026-10-29~). **화면 캡처(여러 장이면 전부)를 링크와 함께** 보내 주세요. 로그인해야 보이는 글도 같습니다(guide §2). 10/29~11/04에 처리 못 한 17건이 이 경우였습니다(같은 기간 게시 불가 14건보다 많음).

## 잘 통과하는 링크
| 유형 | 예 |
|---|---|
| 기사 화면이 있고, **글쓴이의 결론이 기사 내용을 넘지 않는** 글 | 방송 뉴스 화면 인용 영상, 신문 기사 캡처 카드 |
| 판결·기소·압수수색 등 **수사·재판 절차**를 전하는 글 | "○○ 항소심 결심", "특검 압수수색" |
| 정치인의 **공개 발언**(국회·기자회견·공식 SNS)을 옮긴 글 | 발언 영상·속기록 인용 |
| 정부·국회 **공식 발표·자료**를 소개한 글 | 국방부 브리핑, 국회 제출 자료 보도 |

## 게시 불가로 끝나기 쉬운 링크 (자주 나온 사유)
| 유형 | 이유 |
|---|---|
| 부정선거·투표지 영상 등 **선거 부정 주장** | 선관위·법원·언론 근거가 없으면 게시 불가 |
| "○○는 간첩", "명단 유출" 등 **실명 간첩 단정** — 익명 소식통 1곳만 근거 | 명예훼손 위험, 확인 보도 없음 |
| "~하려는 것", "왜 침묵할까" 같은 **암시·의도 단정** | 근거 보도 없는 암시는 요약에서 뺀다 |
| 개인의 사생활·가족 의혹, 일반인의 사망 사건 | 공적 사안이 아니거나 원인이 확인되지 않음 |
| 욕설·구호·서명·집회 독려 위주 | 사실 주장이 없음 |
| AI 생성 영상·출처 불명 캡처 | 진위 확인 불가 |

## 그래도 보내도 되는 경우
SNS 글이 위 사유에 걸려도 **그 안에 실제 보도된 사건이 들어 있으면** 업로더가 그 보도를 출처로 새 글을 **쓸 수 있습니다**("주제 전환 게시", `docs/poster/guide.md` §1-1). 조건은 보도가 최근(게시 작업일 기준 30일 이내)이고, 사적 개인의 사망·사생활이 아니고, 기존 게시물에 없을 때입니다. 이때 SNS 글 자체는 사이트에 링크하지 않습니다.
