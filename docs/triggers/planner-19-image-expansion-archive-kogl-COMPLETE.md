## 3. 프로그래머 오더용 목록 (착수 조건)
1. **`workTitle`·`workYear` 추가**(정책 §4.3 착수 조건): `src/lib/content/schema.ts`의 `ImageCredit` public 전용 선택 필드(권장: A-2는 필수) · 상세 출처 표시(`ImageCreditCaption` 공공누리 문구)에 "작성연도·저작물명" 반영 · `copy-exact` 기대값 · `content/README.md` §3.6 예시. 현재 스키마에는 두 필드가 없다(직접 확인).
2. **A-2 caption 검증(선택, 권장)**: `kind: public`이고 faceNote가 "자료사진"을 포함하면 caption이 `자료사진:`으로 시작하고 "이 사건 당시 사진이 아닙니다"를 포함하는지 `validate-content` 경고. 영어 `imageCaption`의 `Archive photo:` 접두도 같다.
3. **같은 원본 사진 반복 한도 경고(선택)**: `validate-content`가 public 이미지의 `sourcePageUrl`(또는 저장 파일 해시) 기준 게시물 수를 세어 3건을 넘으면 경고.
4. **짧은 변 400px 검사(선택)**: public 저장 이미지(`public/images/**/thumb.jpg`)의 크기를 검증 스크립트가 재도록(이미 B용 400px는 업로더가 수동 점검 — A-2도 수동이면 코드 변경 없음).
5. **공유마당 경유를 인정하는 경우**: `sourcePageUrl` 검증은 이미 http(s) URL이면 통과(public은 `sources[]` 일치 검사 없음)라 **코드 변경 불필요**. 다른 호스트 제한이 필요하면 허용 도메인 목록을 추가(사용자 결정 §11-13에 따라).
6. **(사용자가 §11-16을 채택할 때만)** `kind: news`의 `sourcePageUrl`↔`sources[]` 대조 완화와 `archive` 표시 필드. 권장하지 않는다.
7. 이미 있는 동작(변경 불필요): public 이미지는 `/images/` 저장·`license: kogl-1`·`creditName`·`faceNote` 필수·caption 필수·상세 figcaption에 공공누리 유형 표시·OG·JSON-LD 미사용.

### 2. 프로그래머 오더용 목록 (최종 — 19-1 §3을 대체)
1. **스키마(`src/lib/content/schema.ts`)**: `IMAGE_KINDS`에 `open` 추가. `ImageLicense`: `kogl-1`(public 전용) · `cc-by-2.0` · `cc-by-3.0` · `cc-by-4.0` · `cc0-1.0` · `pd` · `kcc-donated`(open 전용). **지역판 값(`cc-by-2.0-kr` 등)은 만들지 않는다**(조문 확인 전 불가). open 필드: `licenseUrl`(필수), `workTitle`(필수), `workYear`(**상세 페이지에 창작년도가 있으면 필수, 없으면 생략** — 생략하면 caption에 '촬영 연도 미상'+'현재 모습과 다를 수 있습니다.', 19-3), **`sourceSiteName`(필수, 출처 사이트명)**, **`creditNotice`(선택, 원 페이지의 저작권·면책 고지 원문)**, **`donorName`(선택, 기증자가 저작자와 다를 때만 — 19-3)**, **`licenseLabel`(kcc-donated만 필수, 상세 페이지에 표시된 이용조건 글자 그대로; CC BY 4.0이면 `licenseUrl`=CC BY 4.0 legalcode — 19-3)**. 공통 필수: `faceNote`·`caption`(없으면 빌드 중단, 영어 `imageCaption`도)·`sourcePageUrl`·`retrievedAt`·`creditName`·`creditNameEn`. **open도 `sourceType: url` 게시물의 `image`에만**(public·news와 같은 제한, `images[]` 갤러리는 self만). 검증: kind↔license 조합(public↔`kogl-1`, open↔나머지), 버전 없는 `cc-by` 거부, BY-SA·NC·ND·지역판 값은 목록에 없어 자동 거부, `sources[]` 일치 검사는 news에만, news에 license 금지 유지.
2. **상세 출처 표시**: open은 정책 §4.5-11 서식 — ko `사진: {creditName}, 「{workTitle}」({workYear}) · {sourceSiteName} / {라이선스 표기}` + [원 페이지] + [라이선스]. en `Photo: {creditNameEn}, "{workTitle}" ({workYear}) · {sourceSiteName} / {license label}` + [original] + [license]. `creditNotice`가 있으면 함께 표시. **open도 `caption`(영어 `imageCaption`)을 public·news처럼 figcaption의 크레딧 줄 위에 표시한다(19-3 — 소개 문구 A-2 줄의 전제; 현재 `ImageCreditCaption`은 credit이 있는 public·news만 그린다)**. 기증은 이용조건 칸에 `licenseLabel`(CC BY 4.0이면 [라이선스] 링크도), CC0·PD는 정책 §4.5-11 변형 문구. 링크는 기존 public 링크와 같은 `rel`.
3. **`next/image`**: **기증저작물 변형 규칙 하나로 통일** — 상세 페이지 이용조건이 CC BY 4.0(버전 명시)으로 표시된 기증 자유이용은 CC BY 4.0과 같이 다룬다(리사이즈·재인코딩 허용, `next/image` 포함). 이용조건이 그렇게 표시되지 않았거나 다르면 **무변형이며 `next/image` 최적화 제외**. 이를 위해 `kcc-donated`일 때 `licenseLabel`이 "CC BY 4.0" 계열인지로 갈라 최적화 여부를 정하거나, 단순화하려면 **kcc-donated 전부를 `next/image` 제외**로 두는 안(정책 문구보다 보수적, 허용 범위 안)도 가능 — 프로그래머가 택하고 트리거에 근거를 적는다. 그 밖 라이선스는 리사이즈·재인코딩 허용.
