## 교차참조 검증 (D4 재발 방지)
전수 정규식 검증(`grep -no "§[0-9]"`) 후 각 참조가 가리키는 절의 실제 내용과 문맥이 일치하는지 1건씩 대조 완료. 1건 오류 발견 즉시 수정: §5.2 "확인 절차 세부는 §2 남은 질문" → 실제로는 §2 남은 질문 목록에 사진 저작권 항목이 없어 `§0.5 미결 표`로 정정. 그 외 전건 일치.

## 주요 결정사항 (자체 판단 + 근거)
1. **편집 정책을 별도 파일로 분리하지 않고 PRD §6에 인라인 배치**했다. md오더는 "선택"으로 남겼으나, 리뷰어가 최우선 게이트로 보는 항목이라 PRD 본문의 스키마(§3.1 상태 라벨)·저작권 정책(§5.1③)과 상호 참조가 많아 별도 파일로 쪼개면 대조 비용이 커진다고 판단.
2. **카테고리 재제안(§4.2)은 "주제 분류" 축으로, 상태 라벨(§6①)과 분리**했다. 소재가 간첩 행위·의혹 하나이므로 카테고리를 "확정/수사중/의혹"으로 만들면 상태 라벨과 중복되는 설계 결함이 생긴다고 판단해 산업·정치·군사·사이버·해외 5개 주제축으로 제안.
3. **OG 썸네일 재사용 정책 기본값을 "재사용 안 함"으로 제안**했다(D3). 소재 특성상 제3자 이미지에 특정인 얼굴이 포함될 가능성이 있어 초상권 리스크를 낮추는 쪽을 기본값으로 두고, 법률 판단이 필요한 지점은 "확인 필요"로 명시.
