## 주요 결정사항
- 피드는 md 이상에서도 2열(A3만 3열 세로형)로 제한해 268px 4열을 쓰지 않는다. 카드 제목은 3줄 제한.
- 홈 소개 전문은 base에서 `<details>`로 한 줄 접힘, md 이상은 전문 노출(JS 없음).
- 태그는 가로 스크롤 한 줄 칩(칩 링크 44px).
- 영어 헤더 360은 "공산당이싫어요"만 두고 영어 부제는 영어 피드 머리로 이동(768 이상은 헤더 유지).
- 대체 카드: 연한 면 + 가는 테두리 + 선 아이콘(큰 슬롯에서 "이미지 없음" 글자).

## 미해결·이슈
- 사용자 결정 4건(각 notes.md §5): 배너 자리·크기(시안별 다름), 영어 헤더 부제 분리 노출, "더 보기"→"다음 페이지" 이름, 사진 출처 표시 형식·공공누리 유형 표기.
- 실기기(iOS·Android) 주소창 높이 영향은 측정하지 않았다(확인 필요). 줌 200%는 폭 절반 에뮬레이션.
- 한글 줄바꿈이 숫자 중간에서 끊기는 사례가 있다("2/월"). `word-break: keep-all` 검토는 구현 단계 과제로 남긴다(측정 안 함).
- 목업의 사진 출처 이름은 자리표시 예시이며 실제 보도사진은 쓰지 않았다.
