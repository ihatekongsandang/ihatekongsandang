## §6 재구성 요약
- **①허용 출처**: 기존 규칙(등록 언론사·수사기관·판결문, 최소 1건) 유지 + 리뷰어 06 권고(G3) 반영해 "원 매체 URL 원칙"(포털 전재 URL 불허) 추가.
- **②인용문 표기·단정 금지**: 라벨이 없으므로 요약 문장 자체가 사실 확인 단계를 담아야 한다는 원칙을 신설하고, 상황별 예시 표(의혹/수사중/기소/1·2심/확정/종결/발언)를 제시해 운영자가 참고하도록 했다.
- **③실명·얼굴 규칙**: 공인 예외(지위 기준, 리뷰어 05 K1 정의 + 리뷰어 06 G1 판정 앵커)는 그대로 유지. 비공인 인물의 실명 허용 조건을 "라벨이 `유죄판결`+확정일 때"에서 **"인용한 출처가 실제로 유죄 확정을 보도했을 때"**로 재정의했다 — 필드가 아니라 서술 내용으로 판단.
- **④정정·삭제 요청 절차**: 처리기한(3영업일) 등 유지, "라벨 변경" 대신 "요약·출처 수정".
- **⑤갱신 규칙(신설)**: 라벨 전이 대신 요약 문장·출처를 다시 쓰고 상세에 갱신 이력을 한 줄 남긴다. 무죄 확인 시 실명을 이니셜로 되돌리는 원칙도 유지.

## 주요 결정사항 (자체 판단 + 근거)
1. **`speaker.publicFigure` 필드를 두지 않기로 했다** — v0.5에서 리뷰어 06(J6)이 제안했던 필드지만, 프로그래머 03 오더에 없고 "라벨 없이 단순화"라는 이번 사용자 지시의 취지와도 맞지 않는다. 공인 여부는 저장된 값이 아니라 **글을 쓸 때 실명을 쓰는지 이니셜을 쓰는지 자체로 이미 반영되는 판단**이므로 별도 필드가 없어도 정책이 성립한다.
2. **리뷰어 06(v0.5 판정) 보고서의 K1~K4/J1~J7 중 라벨·`kind` 의존 항목(K2 `기소` 정의, K3 enum, J1 `kind: statement` 출처 요건, J2 비공인 발언자 등)은 전부 소멸 처리했다** — 필드 자체가 없어졌으므로 그 결함들이 적용될 대상이 사라졌다. 라벨과 무관한 항목(G3 원 매체 URL 원칙, G1 공인 판정 앵커)만 골라 반영했다.
3. **비공인 실명 허용 조건을 "인용 출처가 실제로 보도한 내용" 기준으로 재정의**했다 — 필드 기반 게이트(`status: 유죄판결` + `courtLevel: 확정`)가 사라진 이상, 같은 보호 수준을 유지하려면 서술 규칙으로 옮겨야 한다. 이 재정의가 이번 v0.6의 핵심 실질 변경이다.
