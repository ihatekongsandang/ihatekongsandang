## 주요 결정사항
- 영어 사이트명 확정 표기는 헤더에서 로고만, 전체 표기는 h1에 둔다(헤더 한 줄화).
- B2 카드는 테두리 없는 면형이라 카드 경계 3:1을 컨트롤에만 적용했다(팀장 판단 필요).
- 홈 소개는 <details>로 접는다(JS 없이 동작, 본문 텍스트는 DOM에 전문 유지).
- 모바일 본문 글자를 줄이지 않았다(17px 유지).

## 미해결·이슈
- 영어 월별 탐색은 새 라우트가 필요(구현 범위 확인 필요).
- 사진 출처 문구는 콘텐츠 스키마의 출처 필드가 필요(기획·프로그래머 확인).
- 상세 배지 "링크"도 삭제함(U4 확장 해석, 확인 필요).
- 실기기 미측정(헤드리스 에뮬레이션). 이 세션 중 포트 충돌로 다른 헤드리스 Chrome에 잠시 붙었을 가능성이 있어 전용 포트(9387)로 바꿔 전부 다시 측정했다.
- B2 sticky 스택은 스크롤 후 캡처를 하지 않았다.
