## 주요 결정사항 (자체 판단 + 근거)
1. **AI 요약 미사용을 기본값으로 제안**(§5) — 큐가 비공개 소재 발굴용이고 최종 판단은 항상 사람이 원문을 직접 보므로 중간 요약의 효용이 낮고, 환각·2차 저작물 리스크가 "추측 금지" 대전제와 충돌하기 때문. 비용도 0원이 된다.
2. **저장 위치는 로컬 전용(.gitignore)**(§6) — 공개 레포에 미게시 민감 소재 후보가 노출되는 것을 막기 위함. 실제 `.gitignore` 수정은 하지 않았다(코드/설정 파일 수정 금지 — 프로그래머 구현 단계에서 할 일).
3. **HTML 스크래핑은 전혀 쓰지 않음**(§2) — 이번에 조사한 모든 출처가 RSS로 충분히 커버되거나(통일부·연합뉴스·38North·RFA), robots.txt로 애초에 차단되어 있어(합참·국방부·국정원) 스크래핑할 대상이 없었다.
4. **런타임은 Python3 표준 라이브러리만 제안**(§7, 최종 확정은 프로그래머) — macOS 기본 설치, 추가 의존성 0, Next.js 앱 코드와 완전히 분리된 독립 스크립트로 두는 것이 "가벼운 단일 스크립트" 요구에 부합한다고 판단.
5. **큐 파일(`data/security-feed/queue.jsonl`) 갱신은 슈퍼바이저만**(§8) — 업로더·슈퍼바이저가 같은 작업 폴더를 쓰는 기존 운영 방식(둘 다 git 인덱스 공유)과 같은 정신으로, 한 파일을 양쪽이 동시에 고치는 충돌을 피하기 위함.
