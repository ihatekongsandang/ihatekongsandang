**작성일**: 2026-11-09 | **작성 세션**: 디자이너 C (Sonnet 5.5)

## 요약 (3줄)
1. 방향 C(카드 그리드 중심) 시안 C1(테두리형 1/2/3/3)·C2(면형 1/2/3/4 + 첫 카드 2칸)·C3(이미지 꽉 참 2/2/3/4 + 가로형 첫 카드)를 정적 HTML로 만들고 360·768·1280 스크린샷(첫 화면+전체)을 찍었다.
2. 사진 카드 크레딧 칩, 새 대체 카드, "링크" 표기 삭제, 배너 자리 변경(U1), 소개 접힘(U3)을 반영했다.
3. 수치 목표는 모바일 본문 줄 길이(ko 24자)를 뺀 전 항목을 달성했다. 측정은 헤드리스 Chrome 실측이다.

## 주요 결정사항
- 홈 머리 목표(≤240)를 위해 base 태그를 한 줄 레일로 바꿨다(B 방향 요소 차용, notes D-1).
- 영어 base 헤더는 부제를 피드 h1로 옮겨 57px.
- 상세는 이미지를 위로 올리고 반복 제거, 원문 이동을 첫 화면 안에 둠. "원문 미리보기" 라벨은 시각에서 숨김(D-4).
- 배너: lg 이상은 현행 세로 탭, base·md만 세 안이 다르다.
