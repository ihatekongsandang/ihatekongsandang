측정 식(전 시안 동일):
- **첫 화면 카드** = 카드 전체가 화면 안에 있고, 헤더 아래이며, 고정(fixed) 요소와 겹치지 않는 카드 수.
- **줄당 글자** = 본문 안 3줄 이상인 문단·목록 항목마다 (글자 수 ÷ 실제 줄 수)의 평균. 줄 수는 글자 상자(Range)의 줄 위치로 셌다. 디자이너들 값과 식이 달라 숫자가 조금 다르다(예: C 43 → 46.9).
- **터치 44 미만** = 보이는 `a·button·summary·select·input` 중 높이 43.5 미만. 카드 제목 링크(카드 전체를 덮음)·화면 밖 건너뛰기 링크·문장 속 링크는 제외(브리프 §5).
- **글자 대비** = 보이는 글자 요소 전부의 글자색 대 실제 배경(조상 배경을 겹쳐 계산, 배경 그림 위는 흰·검정 중 나쁜 값). 9개 합 **13,547건** 검사.
- **포커스** = Tab마다 포커스 요소(또는 조상 4단계)의 outline/box-shadow 유무, 그리고 고정 요소에 **완전히** 가려졌는지(WCAG 2.2 2.4.11).

측정 한계: 실기기(iOS·Android) 주소창·홈 인디케이터는 재지 않았다(확인 필요). 줌 200%는 폭 절반 리플로우로 쟀고, 글자 확대 자체는 재지 않았다. 스크린리더 낭독은 확인하지 않았다.
