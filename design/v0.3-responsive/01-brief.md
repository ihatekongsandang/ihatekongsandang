## 3. 방향 3개 (서로 겹치지 않게)

세 방향은 **무엇을 첫 화면의 주인공으로 두는지**로 나뉜다. 같은 문제를 다른 방법으로 푼다.

| | A — 읽기 중심 | B — 탐색 중심 | C — 카드 그리드 중심 |
|---|---|---|---|
| 한 줄 | "한 건을 끝까지 읽기 좋게" | "원하는 주제를 빨리 찾게" | "여러 건을 한눈에 훑게" |
| 주인공 | 상세 본문·제목 글자 | 태그·내비·페이지 이동 | 카드 이미지와 그리드 리듬 |
| 피드 카드 | 가로형 목록 카드(작은 썸네일 + 제목) — 모바일 첫 화면 4장 이상 | 표준 세로 카드 + 탐색 막대(태그 레일)가 늘 함께 보임 | 이미지 우선 세로 카드. 폭마다 열 수·이미지 비율 조정 |
| 상세 | 본문 우선 재배치, 읽기 글자 체계(크기·줄간격·줄 길이) | 상세 끝에 같은 태그 이동·이전/다음 글 이동 | 상세 상단 큰 이미지 + 정돈된 메타, 이미지 반복 제거 |
| 태블릿 | 읽기 컬럼 + 여백, 세로·가로 다른 컬럼 폭 | `lg`에서 왼쪽/오른쪽 고정 태그 사이드바 | `md` 2열 → `lg` 3열, 카드 크기 균일화 |
| 다루는 진단 번호 | #4·#5·#9·#1·#2 | #1·#10·#11·#8·#7 | #3·#6·#14·#16·#2 |

### 방향 A — 읽기 중심 (디자이너 A)

- **피드**: base에서 카드는 왼쪽(또는 오른쪽) 썸네일 + 제목 2~3줄의 가로형으로 한다. 썸네일도 이미지이므로 C3 "제목+이미지"를 지킨다. 썸네일 비율 16:9 유지 또는 근거를 대고 변경. 목표는 첫 화면 카드 **4장 이상**(360×740).
- 홈 머리 영역은 h1을 1줄로 줄이고, 소개 문단은 접거나 1~2줄로 줄인다. 소개 전문은 `/about`에 있다. 머리 영역 문구 변경이 필요하면 사용자 결정 항목으로 표시한다.
- **상세**: 순서를 바꾼다 — 제목 → 요약 → 원문 이동(첫 화면 안) → 본문 → 배경 보도 → 공유 → 태그. 공유 위치는 변주 축으로 정한다.
- **읽기 글자**: 본문 ko 17~18px·줄간격 1.75 안팎, 컬럼 최대 폭 ko 약 34~38em, en 약 65~72ch(현행 en 102자/줄 해소). 소개·약관 본문도 같은 체계를 쓴다(#9).
- 변주 축(시안 A1·A2·A3):
  1. 피드 카드 형태: A1 가로형(썸네일 왼쪽) / A2 가로형(썸네일 오른쪽·날짜 위) / A3 base 가로형 + `md` 이상 세로형 혼합
  2. 공유 위치: A1 본문 끝 / A2 제목 아래 작은 줄 + 본문 끝 반복 / A3 모바일 하단 고정 공유 막대(배너와 충돌 해결 필수)
  3. 글자 체계: A1 17px·1.75 / A2 18px·1.8 / A3 16px·1.75 + 넓은 문단 간격

### 방향 B — 탐색 중심 (디자이너 B)

- **내비**: 헤더 터치 영역 44px. base에서 태그 칩을 **가로 스크롤 한 줄**(또는 접힘)로 바꿔 머리 영역 높이를 줄인다(현행 4줄 130px). 스크롤 가능하다는 신호(끝 페이드 등)와 키보드 접근을 함께 설계한다.
- **페이지 이동**: "더 보기"의 실제 동작(다음 페이지로 이동)에 맞는 이름과 모양, 페이지 번호 바로가기, 첫/끝 이동. 무한스크롤 하이브리드를 넣는다면 링크 우선 구조를 지킨다(C8).
- **전체 태그(325개)**: 건수 묶음(예: 10건 이상 / 3~9건 / 1~2건), 가나다 묶음, 또는 페이지 안 찾기 안내. 검색 입력은 JS·의존성 범위를 적는다.
- **영어**: 태그 링크 없이 영어 방문자의 탐색 수단을 제안한다(예: 월별 묶음 링크는 새 라우트가 필요하므로 "구현 범위 확인 필요"로 표시). 헤더 3줄(102px) 해소안을 반드시 넣는다(#7).
- **상세 끝**: 같은 태그 글로 이동, 이전/다음 글. 새 데이터는 필요 없고 기존 태그·날짜로 만들 수 있다. 영어는 C7을 지킨다.
- 변주 축(B1·B2·B3):
  1. 태그 탐색 형태: B1 가로 스크롤 칩 레일 / B2 "주제" 버튼 → 펼침 패널(JS 없이 `<details>`) / B3 `lg` 이상 고정 사이드바 + base 레일
  2. 헤더: B1 한 줄 압축(언어 전환을 아이콘+짧은 표기로) / B2 2단(로고 줄 + 내비 줄, 스크롤 시 1단) / B3 base 하단 탭 막대(배너 자리 재조정 포함)
  3. 페이지 이동: B1 번호형 / B2 "더 보기"(같은 화면에 이어 붙이기, 점진적 향상) + 번호 / B3 이전·다음 + 페이지 선택

### 방향 C — 카드 그리드 중심 (디자이너 C)

- **그리드**: 폭별 열 수·간격·이미지 비율을 다시 정한다. 제안 출발점: base 1열(또는 2열 소형), `md` 2열, `lg` 3열, `xl` 3~4열. 4열을 유지하면 카드 폭 268px에서 이미지 속 글자가 읽히지 않는 문제(#3)를 어떻게 푸는지 보여야 한다.
- **카드 높이 균일화**: 제목 줄 수 제한(`line-clamp`, 잘린 제목의 전체 문구는 상세·`title`로 확인), 메타 줄 정리. 모든 카드에 붙는 "링크" 유형 표기의 처리를 제안한다(#14, 없애려면 사용자 결정 표시).
- **첫 카드**: `md` 이상에서 가장 최근 카드를 크게 보여 줄 수 있다. 단 라벨·섹션 이름 없이(C2) 최신순 레이아웃의 일부로만.
- **이미지**: 자체 제작 카드 이미지가 제목을 반복하는 문제에 대한 화면 쪽 해법(비율·크롭·크기). 이미지 제작 규칙을 바꾸는 안은 "콘텐츠 규칙 변경 — 사용자 결정"으로 따로 적는다.
- **브랜드**: 담백한 범위 안에서 로고 글자·강조색 1개·카드 모서리·테두리 체계를 정한다. 비텍스트 대비 3:1 문제(#13)의 해법(테두리 진하게 또는 면 구분)을 넣는다.
- 변주 축(C1·C2·C3):
  1. 열 구성: C1 1/2/3/3 / C2 1/2/3/4(4열 대응 포함) / C3 base 2열 소형 / 2 / 3 / 4
  2. 첫 카드 강조: C1 없음 / C2 `md` 이상 첫 카드 2칸 / C3 `lg` 이상 첫 카드 가로형 전폭
  3. 카드 면 처리: C1 테두리형(대비 3:1 테두리) / C2 면형(테두리 없이 배경 단차) / C3 이미지 꽉 참 + 아래 글자

### 배너(#2) — 세 방향 공통 숙제

닫기 버튼 없음은 사용자 지시이므로 유지한다. 각 시안은 base·`md`에서 배너 자리를 하나 정해 스크린샷에 보여야 한다. 후보: 현행 오른쪽 아래 / 크기 축소 / 하단 전폭 띠(본문 여백 확보) / 헤더 아래 고정 한 줄 / 스크롤 방향에 따라 숨김(JS 필요, 표시). 현행과 다른 안은 사용자 결정이 필요하다(§6).
