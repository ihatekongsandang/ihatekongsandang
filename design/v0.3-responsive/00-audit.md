### 잘 되어 있어 유지할 것

- 가로 넘침 0/56. 카드 이미지 비율 16:9 고정(빈 이미지도 같은 비율의 슬롯을 차지해 CLS가 없다). `next/image`·핫링크 실패 시 대체 처리.
- 공유 버튼 3개가 44px 높이이고, 모바일에서 3등분 그리드다(`share-buttons.tsx`).
- 글자 대비 전 항목 AA 통과. `:focus-visible` 링, 건너뛰기 링크, 카드 하나에 탭 정지점 하나, `lang` 표기.
- 갱신 표시(평문 "MM/DD 갱신"), "Korean only" 표시, 약관 개정일 — 기존 기능이라 그대로 유지해야 한다.

## 3. 상위 문제 5개 (브리프의 출발점)

1. **모바일 첫 화면에 카드 0~1장**(#1) — 머리 영역(h1·소개·칩 4줄)이 460px를 차지한다.
2. **고정 배너가 모바일·태블릿 본문을 가림**(#2) — 닫기가 없어 디자인으로 자리를 정해야 한다. 배치 변경 범위는 사용자 결정이 필요하다.
3. **카드 제목 길이 제어 없음 + 이미지 속 글자 중복**(#3) — 4열·영어에서 카드가 5~8줄로 늘어진다.
4. **상세 읽기 흐름이 거꾸로**(#4·#5) — 공유·미리보기가 본문보다 먼저 나오고, 원문 이동 버튼이 첫 화면 밖에 있다. 영어 본문은 줄당 102자다.
5. **태블릿 구간 미설계**(#6·#7) — 768~1024에 맞춘 열 수·여백·헤더·배너 규칙이 없다(`md` 미사용).
