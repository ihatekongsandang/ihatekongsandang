# B3 notes — lg 이상 고정 사이드바 + base 레일 · 하단 탭 막대 · 이전/다음 + 페이지 선택

> 디자이너 B · md오더 04-B · 방향 B(탐색 중심). 목업: `mockup.html`(정적, 외부 요청 없음). 스크린샷은 헤드리스 Chrome으로 `file://` 목업을 열어 실측했다(`docs/tools/designer-04-B/shoot.mjs`). 측정 원자료 `docs/tools/designer-04-B/measure-output.json`.

## 1. 방향과 변주 축 선택
- 태그 탐색 = B3 lg 이상 사이드바 + base 레일 / 헤더 = B3 base 하단 탭 막대 / 페이지 이동 = B3 이전·다음 + 페이지 선택
- 헤더: base 53px 얇은 막대(로고 + English) + 하단 탭 막대 56px(홈·주제·소개) / md 이상 상단 홈·소개 노출, 탭 막대 숨김
- 태그 탐색: base·md 칩 레일(B1과 같은 규칙) / lg 이상 왼쪽 고정 사이드바 224px(상위 10개 주제 + 건수별 3묶음 + 전체 주제 링크, 행 44px)
- 페이지 이동: 이전 · "N / 18 페이지" select + 이동 버튼(<form method=get>, JS 없이 동작) · 다음
- 열 수(base/sm/md/lg/xl): 1 / 1 / 2 / 2(사이드바) / 3(사이드바)
- 카드 면: 이미지 둥근 모서리 + 카드 아래 구분선(#8a8a94 3.4:1)
- 배너 자리: base: 탭 막대 바로 위 띠 48px(둘 합쳐 하단 104px) / md: 하단 전폭 띠 / lg 이상 세로 탭
- 사진 출처 표시 자리: 카드 아래 메타 줄 맨 앞("사진: 대통령실 · 2026년 11월 9일")
- 새 대체 카드(회색+빨간 줄 카드 대체): 첫 태그 큰 글자("#이진숙") + 점선 테두리 + "대표 이미지 없음"
- 영어: 영어: 얇은 막대 + 하단 탭(Home·Months·About), lg 이상 사이드바에 월별 목록. **월별 새 라우트 필요 — 구현 범위 확인 필요**. 태그 링크 없음(C7).
- 상세 순서: B1과 같은 순서. lg 이상은 사이드바 옆 컬럼(33rem)에 왼쪽 정렬.
- 사용자 결정 반영: U1=a(배너 자리·크기 변경, 닫기 없음 유지) · U2=a(다크 미도입, 토큰 표에 값만) · U3=a(홈 소개 D1 확정문 모바일 한 줄 + "더보기", 문구 그대로, `<details>`) · U4=a(카드·상세의 "링크" 유형 표기 삭제) · U5=a(시스템 폰트).

## 5. 장단점
- 장점: lg 이상 홈 첫 카드 y=214, 6장이 보여 훑기 효율이 가장 높다. 사이드바가 태블릿 가로(1024)의 빈 공간을 쓴다.
- 단점: 하단 탭 + 배너로 base 화면 아래 104px를 쓴다. 사이드바·탭이 새 컴포넌트라 구현량이 가장 많다. 1280 3열 카드가 267px라 이미지가 150px(자체 제작 글자 이미지는 읽기 어려움 — 사진 교체 시 문제 완화).

## 6. 사용자 결정 필요
- 영어 월별 탐색: 새 라우트 필요 → 구현 범위 확인 필요(없으면 영어는 시간순만).
- 영어 사이트명 확정 표기를 헤더와 h1로 나누는 배치(헤더는 로고만, 전체 표기는 h1)— B1·B2·B3 공통.
- 상세 끝 "이전/다음 글"·"같은 태그 글": 기존 태그·날짜로 만들 수 있어 새 데이터는 없다. 도입 여부 확인.
- 사진 출처 문구("사진: {기관·언론사}")는 콘텐츠 스키마에 출처 필드가 필요하다 → 기획·프로그래머 확인 필요.
- 새 대체 카드는 지금의 회색+빨간 줄 카드를 대체한다. 첫 태그·출처명을 쓰는 안이 있으면 스키마에서 값을 가져와야 한다.
- 카드 아래 "링크" 삭제 외에 상세 배지 "링크"도 삭제했다(U4 확장 해석 — 확인 필요).
- 상세 미리보기 라벨(U6)은 현행 문구 유지.
- 배너 하단 띠·sticky 줄은 U1=a 범위 안이지만 레이아웃이 현행과 크게 다르다 — 선정 시 재확인.
