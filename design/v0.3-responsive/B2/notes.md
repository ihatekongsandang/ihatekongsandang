# B2 notes — "주제별로 보기" 펼침 패널 · 2단 헤더 · "다음 12건 보기" + 번호

> 디자이너 B · md오더 04-B · 방향 B(탐색 중심). 목업: `mockup.html`(정적, 외부 요청 없음). 스크린샷은 헤드리스 Chrome으로 `file://` 목업을 열어 실측했다(`docs/tools/designer-04-B/shoot.mjs`). 측정 원자료 `docs/tools/designer-04-B/measure-output.json`.

## 1. 방향과 변주 축 선택
- 태그 탐색 = B2 "주제" 펼침 패널(<details>, JS 없음) / 헤더 = B2 2단 / 페이지 이동 = B2 "더 보기 + 번호"
- 헤더: ko 2단(로고 줄 56 + 내비 줄 48, 스크롤하면 로고 줄만 사라짐 sticky top:-56px) / en 한 줄 56 + Menu(details)
- 태그 탐색: "주제별로 보기 325" 버튼 → <details> 패널(10건 이상 13개 / 3~9건 45개 중 8개 / 1~2건 267개)
- 페이지 이동: "다음 12건 보기 · 2 / 18 페이지" 큰 버튼(실제 ?page=2 링크, JS 있으면 이어 붙이기는 점진적 향상) + 번호
- 열 수(base/sm/md/lg/xl): 1 / 1 / 2 / 3 / 3
- 카드 면: 면형(페이지 배경 #f4f4f5 위 흰 카드, 테두리 없음). 카드 경계는 제목·이미지로 식별, 컨트롤 테두리는 3.4:1
- 배너 자리: 모든 <1024 폭: 헤더 아래 sticky 한 칸(48px, 2줄). lg 이상 세로 탭. 스택 높이 154px(base)
- 사진 출처 표시 자리: 사진 바로 아래 캡션 한 줄("사진: 대통령실", 12px 7.7:1)
- 새 대체 카드(회색+빨간 줄 카드 대체): 출처 이름 첫 글자 원 + 출처명 + "원문에서 확인"(#e4e4e7 면)
- 영어: 영어: 한 줄 헤더 57px + Menu(<details>), 피드 위 "Browse by month" 펼침 패널(월 칩). **새 라우트 필요 — 구현 범위 확인 필요**. 태그 링크 없음(C7).
- 상세 순서: B1과 같은 순서. 상세는 흰 카드형 컬럼(페이지 배경 #f4f4f5 위)이고, 사진 출처는 이미지 아래 캡션.
- 사용자 결정 반영: U1=a(배너 자리·크기 변경, 닫기 없음 유지) · U2=a(다크 미도입, 토큰 표에 값만) · U3=a(홈 소개 D1 확정문 모바일 한 줄 + "더보기", 문구 그대로, `<details>`) · U4=a(카드·상세의 "링크" 유형 표기 삭제) · U5=a(시스템 폰트).

측정 한계: 데스크톱 폭의 "첫 화면 카드"는 고정 하단 요소를 제외한 값(`fullyVisibleUnobscured`)도 같다. 실제 iOS·Android 기기는 측정하지 않았다(에뮬레이션). B2의 sticky 스택(스크롤 시 로고 줄만 사라짐)은 CSS로 구현했지만 스크롤 후 캡처는 하지 않았다. 전체 캡처(`-full.png`)의 고정 배너·탭은 캡처 순간 위치에 한 번 찍힌다(진단표와 같은 한계).

## 5. 장단점
- 장점: 주제 325개를 건수 묶음으로 보여 줘 "찾기"가 가장 강하다. 홈 머리가 가장 낮다(스택 아래 141px).
- 단점: base 상단 고정 스택이 154px(헤더 2단 + 배너)로 가장 크다(스크롤하면 로고 줄 56px가 빠져 98px). "더 보기" 이어 붙이기는 JS(점진적 향상)가 필요하고 목업은 링크만 보여 준다.

## 6. 사용자 결정 필요
- 영어 월별 탐색: 새 라우트 필요 → 구현 범위 확인 필요(없으면 영어는 시간순만).
- 영어 사이트명 확정 표기를 헤더와 h1로 나누는 배치(헤더는 로고만, 전체 표기는 h1)— B1·B2·B3 공통.
- 상세 끝 "이전/다음 글"·"같은 태그 글": 기존 태그·날짜로 만들 수 있어 새 데이터는 없다. 도입 여부 확인.
- 사진 출처 문구("사진: {기관·언론사}")는 콘텐츠 스키마에 출처 필드가 필요하다 → 기획·프로그래머 확인 필요.
- 새 대체 카드는 지금의 회색+빨간 줄 카드를 대체한다. 첫 태그·출처명을 쓰는 안이 있으면 스키마에서 값을 가져와야 한다.
- 카드 아래 "링크" 삭제 외에 상세 배지 "링크"도 삭제했다(U4 확장 해석 — 확인 필요).
- 상세 미리보기 라벨(U6)은 현행 문구 유지.
- 배너 하단 띠·sticky 줄은 U1=a 범위 안이지만 레이아웃이 현행과 크게 다르다 — 선정 시 재확인.
