> 디자이너 C · 04-C · 2026-11-09. 측정: `docs/tools/designer-04-C/shoot.mjs`(헤드리스 Chrome, `file://` 목업), 원자료 `metrics.json`·`metrics-summary.txt`. 시안 재현: `node docs/tools/designer-04-C/build.mjs`.
> 목업의 사진은 전부 회색 자리표시 도형이다(실제 보도사진 없음). 출처 이름("사진: 대통령실" 등)은 예시 문구다. 제목은 실제 게시물 제목(최장 115자·최단 33자 포함 12건)이다.

## 1. 방향과 변주 축
- 방향 C(카드 그리드 중심). 변주: 열 구성 C3(base 2열 소형 /2/3/4) · 첫 카드 lg 이상 가로형 전폭 · 카드 면 이미지 꽉 참(면·테두리 없음).
- 공통: 홈 머리를 압축(h1 22px + 소개 1줄 + "더보기" + 태그 한 줄 레일 + 건수 줄), 헤더 터치 44, 상세는 "제목 → 메타 → 큰 이미지 한 번 → 원문 이동 → 요약 → 본문" 순서(이미지 반복 제거), 카드 "링크" 표기 삭제.
- 사진 카드: 이미지 왼쪽 아래에 크레딧 칩("사진: 대통령실" / "사진: 언론사"), 흰 글자 + 어두운 반투명 바탕(최악 흰 사진 위 10.03:1). 상세에서는 이미지 아래 캡션 줄에 출처를 한 번 더 적는다.
- 사진 없음 대체 카드: 회색 줄 + 빨간 막대 카드를 없애고, 바탕 `--surface` + 안쪽 `--bd` 테두리(3:1) + 이미지 아이콘 + "대표 이미지 없음" + "출처 · 언론 보도" 두 줄. 이미지 칸과 같은 16:9라서 높이가 맞는다.

## 4. 시안 고유 사항
- 공유는 본문 뒤(배경 보도 앞).
- 약점: 360 2열 카드는 제목이 11자/줄로 대부분 5줄째에서 잘린다(실제 제목 평균 65자 안팎 → 훑기는 되지만 제목만으로 내용 파악이 어렵다). 14px 제목은 세 안 중 가장 작다. 2열 카드가 좁아 크레딧 문구("사진: 대통령실")가 이미지 폭의 70%를 차지한다. 첫 카드 전폭 때문에 lg 첫 화면에 카드가 1장만 완전히 보인다.

| D-4 | 상세의 "원문 미리보기" 제목은 시안에서 스크린리더 전용으로 숨겼다(이미지가 위로 올라가 라벨이 맞지 않음). 원문 og 제목·요약 인용 상자는 이번 목업에 넣지 않았다(측정 게시물에는 없음) — 있는 게시물의 배치는 기획자 확인 필요(U6) |
