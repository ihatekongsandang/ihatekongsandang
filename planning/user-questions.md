# 사용자 결정 필요 항목 (기획자 06-prd-v0.6, 2026-09-21 정비)

> `planning/prd.md` v0.6 작성 중 정리. 사용자 답변 6~14(2026-09-21)를 전부 반영해 답변 완료 항목으로 이동했다. 🔴 사용자 지시로 사건 상태 라벨·게시물 종류(`kind`) 구분이 폐지되어, 라벨 관련 세부 질문(공인 예외 범위 등은 실명 규칙에 그대로 남아 있어 유지)은 이번 정비에서 함께 정리했다.

## 참고 — 질문은 아니지만 사용자가 알아야 할 기본값·정책 채택

- **AI 작성 고지**: `/about`에 "게시 파일은 AI 세션이 작성한다"는 사실을 **고지하지 않음**을 기본값으로 채택했다(PRD §0.5·§1). 사용자 확정 사항이 아니라 기획자·리뷰어 판정에 따른 기본값이며, 이견이 있으면 언제든 변경 가능하다. 또한 이 기본값과 별개로 「인공지능 발전과 신뢰 기반 조성 등에 관한 기본법」 제31조②(생성형 AI 결과물 표시 의무)의 적용 여부는 **법률 자문이 필요한 확인 필요 사항**으로 남아 있다(§1).
- **공인 예외의 범위**: PRD §6③에서 "공인"을 선출직·고위 공직자·**정당 간부·공공기관장 등** 공적 지위 기준으로 정의했다(상태 라벨 폐지와 무관하게 실명·얼굴 규칙에 그대로 유지). 정당 간부·공공기관장까지 포함할지는 기획자·리뷰어 판정이며, 사용자가 이 범위에 이견이 있으면 알려달라(채택 사실 고지).
- **`useSourceImage` 기본값**: `false`로 최종 확정됐다(리뷰어 04 판정, §3.1). 재논의 불필요.
- **🔴 사건 상태 라벨·게시물 종류(`kind`) 폐지**: v0.5까지 있던 `status`(의혹/수사중/기소/유죄판결/종결)·`closureReason`·`kind`(형사 사건/발언·논평) 등은 사용자 지시로 전부 삭제됐다(§3·§6). 이전 버전에서 논의됐던 라벨 enum·전이 규칙 관련 세부 질문(예: `closureReason` 값 구성)은 필드 자체가 없어져 **모두 소멸**했다.
